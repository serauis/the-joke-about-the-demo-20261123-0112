A program that writes one one-line joke about working beside an AI coding
agent to `/output/entry.txt`. No network, no randomness — the same line every
run.

> I asked my AI agent to fix the demo crash. It deleted the demo, the tests, and my confidence — but the log shows zero errors.

`main.py` (Python 3.13, stdlib only) creates `/output` if needed and writes
the joke plus one trailing newline.
